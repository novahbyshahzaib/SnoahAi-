v4.1

🆕 What's New in v4.1

  • Plugin / Extension Worker Refactor 🧩 — Plugin execution is now handled by a robust inline Blob Worker with structured message passing, safer runtime evaluation, and explicit error returns to the main thread for reliable installs and debugging.
  • Chat Branching Upgrade 🌿 — Branch controls now support creating and deleting the selected branch directly from the branch bar, making branch management faster and cleaner during long conversations.
  • Smarter Agentic URL Deduplication 🔗 — The agentic web search no longer visits the same page twice. URLs are now normalized before deduplication — stripping http:///https://, www. prefix, and trailing slashes — so https://example.com/ and http://www.example.com are correctly treated as identical. Saves browse-depth budget for genuinely new sources.
  • Agentic Log Size Safeguards 💾 — Agentic search logs saved to chat history are now capped at 8 entries per response, with each reasoning preface limited to 500 characters. This prevents the chat history from filling up browser localStorage on long multi-URL research sessions.
  • Consistent Branch Naming 🌿 — Branched conversations are now always numbered from the first branch (e.g. "Branch 1", "Branch 2", …) for clarity in the sidebar history.
